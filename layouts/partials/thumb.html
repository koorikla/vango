{{- /* A fixed-size gallery thumbnail: AVIF, falling back to the WebP that was here before it. Params: img (image resource), alt, width, height, vt No srcset — these are laid out at one size and the grid does not change it. The keeps the WebP, so a browser without AVIF sees exactly what it saw before; AVIF is only ever an upgrade. Only for photographs, on the same reasoning as img.html: a lossy codec is the wrong tool for flat artwork. And nothing smaller than this — the 120px room thumbs on the one-pager are ~4 kB each, which is around where AVIF's container overhead starts winning back what its compression saves. */ -}} {{- $img := .img -}} {{- $w := .width | default 800 -}} {{- $h := .height | default 600 -}} {{- $spec := printf "%dx%d Center" $w $h -}} {{- $webp := $img.Fill (printf "%s webp q80" $spec) -}} {{- if ne (path.Ext $img.Name) ".png" }} {{- end }}
